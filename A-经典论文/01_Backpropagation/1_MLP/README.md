# 实验 1：从零实现基础 MLP（XOR）

## 一、任务理解

本实验不属于论文原始实验，而是用于验证反向传播与动量更新实现是否正确的小型自检任务。论文自身的实验是镜像对称检测和家谱关系学习，另有对应的独立实验。

任务：用带一个隐藏层的 Sigmoid 多层感知机学习 XOR。输入为两个取值 0 或 1 的数，两者不同时输出 1，相同时输出 0。训练使用全部 4 个样本，没有独立的验证集或测试集。

达标现象：全批量训练后总误差降到 `1e-3` 以下，且四个输入的输出概率经 0.5 阈值判定后全部预测正确。

当前范围与简化：只有这一个网络结构，不做方法对比；隐藏层宽度、学习率、动量系数、初始化范围和 epoch 数都是当前实现的选择，并非论文针对 XOR 给出的设置。

## 二、理论实现

设一个 batch 有 $B$ 个样本，第 $l$ 层输入宽度为 $n_{l-1}$、输出宽度为 $n_l$，$L$ 表示输出层。

| 符号 | 含义 | 形状 |
|---|---|---|
| $A^{(l-1)}$ | 本层输入；第 0 层就是原始数据 $X$ | $(B,n_{l-1})$ |
| $W^{(l)}$ | 本层连接权重 | $(n_{l-1},n_l)$ |
| $b^{(l)}$ | 本层偏置；对 batch 中每行广播 | $(n_l,)$ |
| $Z^{(l)}$ | 激活前的线性组合 | $(B,n_l)$ |
| $A^{(l)}$ | Sigmoid 后的激活 | $(B,n_l)$ |

前向传播：

$$
Z^{(l)}=A^{(l-1)}W^{(l)}+b^{(l)},\qquad
A^{(l)}=\sigma\!\left(Z^{(l)}\right),\qquad
\sigma(z)=\frac{1}{1+e^{-z}}.
$$

偏置向量等价于论文中“恒为 1 的额外输入及其连接权重”。总误差为

$$
E=\frac12\sum_{c,j}\left(\hat y_{c,j}-y_{c,j}\right)^2,
$$

对 batch **求和而不是取平均**，因此 batch 大小会影响梯度尺度。输出层误差信号为

$$
\delta^{(L)}=(A^{(L)}-Y)\odot A^{(L)}\odot(1-A^{(L)}),
$$

隐藏层误差信号向前递推：

$$
\delta^{(l)}=\left(\delta^{(l+1)}(W^{(l+1)})^\top\right)\odot A^{(l)}\odot(1-A^{(l)}).
$$

把 batch 中所有样本的贡献相加：

$$
\frac{\partial E}{\partial W^{(l)}}=(A^{(l-1)})^\top\delta^{(l)},\qquad
\frac{\partial E}{\partial b^{(l)}}=\sum_c\delta_c^{(l)}.
$$

参数用动量梯度下降更新（$v$ 为速度，初始为 0，$\mu$ 为动量系数，$\alpha$ 为学习率）：

$$
v\leftarrow\mu v-\alpha\nabla E,\qquad \theta\leftarrow\theta+v.
$$

## 三、运行环境

- Python：3.8 或更高版本。
- numpy：1.20 或更高版本，用于数据处理与矩阵运算。

无需深度学习框架。

## 四、代码说明

### 1. 文件职责

| 文件 | 主要职责 |
|---|---|
| `main.py` | 统一入口：生成 XOR 数据，调用训练，检查收敛，打印训练日志和测试输入的预测。 |
| `config.py` | `EXPERIMENT` 集中管理随机种子、网络结构、初始化范围、epoch 数、学习率、动量系数、收敛阈值和日志间隔；`TEST_INPUTS` 为训练后查看预测的输入。 |
| `model.py` | `sigmoid`（数值稳定写法）、`initialize_parameters`、`forward`（同时返回各层缓存）、`total_error`、手写的 `backward`、动量更新类 `MomentumSGD`，以及全批量训练函数 `train`。 |

本实验规模很小，数据生成、评估和打印都直接写在 `main.py` 中，不单独拆分模块。

### 2. 默认配置与数据路径

- 网络为 `2 -> 4 -> 1`，随机种子 `7`，权重和偏置在 $[-0.5,0.5]$ 内均匀初始化。
- 全批量训练 `5000` 个 epoch，学习率 `0.7`，动量系数 `0.9`；每 `1000` 个 epoch 打印一次总误差。
- 收敛阈值为 `1e-3`，训练结束后总误差不低于该值时程序抛出 `AssertionError`。
- 数据由代码直接生成，无需下载，不涉及数据路径。
- 若要查看其他输入的预测，修改 `config.py` 中的 `TEST_INPUTS`，每个元素只能是 0 或 1。

本实验没有对应的论文规模设置，因此不存在需要调整以接近论文规模的参数。

### 3. main 执行流程

最小运行方式：`python main.py`。

1. 设置 NumPy 输出精度，生成 XOR 数据。
2. `train` 初始化参数，每个 epoch 做一次前向传播、反向传播和动量更新，并记录更新前的总误差。
3. 打印每隔 1000 个 epoch 的总误差。
4. 重新计算最终训练总误差并与阈值比较，未达标则报错终止。
5. 对 `TEST_INPUTS` 打印“输入 -> 正确标签 -> 输出概率 -> 预测类别”。

检查方式：总误差随 epoch 下降并低于 `1e-3`，且四个输入的预测类别与正确标签一致，说明反向传播与动量更新工作正常。本实验不绘图、不保存文件。

## 五、实验结果

论文预期：反向传播能为隐藏单元学到有用的内部表示，使网络解决单层网络无法解决的问题。XOR 是此类问题的典型例子，但不是论文报告的实验。
