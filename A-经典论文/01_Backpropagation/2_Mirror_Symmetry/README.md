# 实验 2：6 位镜像对称

## 一、任务理解

复现反向传播论文中的镜像对称实验。输入是 6 位二进制向量，仅当 $x_1=x_6,\ x_2=x_5,\ x_3=x_4$ 同时成立时标签为 1，否则为 0。训练集为全部 $2^6=64$ 种输入，其中对称向量 8 个。网络只有 2 个隐藏单元。

判断标准：训练后 64 个输入全部分类正确（概率阈值 0.5），对称输入的输出概率接近 1，非对称输入接近 0。

论文给出的设置：`6 -> 2 -> 1` 结构、学习率 0.1、动量 0.9、初始权重在 $[-0.3,0.3]$ 内随机、训练 1425 次全批量扫描。当前实现的选择：Sigmoid 激活、半平方误差、随机种子 `1`、偏置同样随机初始化、额外的测试输入。该任务对初始化较敏感，默认种子是为稳定得到全部正确而选定的。本实验没有留出集，目标是拟合全部 64 个样本。

## 二、理论实现

定义三组镜像差

$$d_1=x_1-x_6,\quad d_2=x_2-x_5,\quad d_3=x_3-x_4.$$

网络为 $6\to2\to1$，输入 $X\in\mathbb R^{N\times6}$（$N=64$），各层使用 Sigmoid $\sigma$：

$$H=\sigma(XW_1+b_1),\quad \hat y=\sigma(HW_2+b_2),$$

其中 $W_1\in\mathbb R^{6\times2}$，$W_2\in\mathbb R^{2\times1}$。两个隐藏单元可分别检测加权差的正、负方向，输出层在两个检测器都未激活时判为对称。

损失为半平方误差

$$E=\tfrac12\sum_i(\hat y_i-y_i)^2.$$

反向传播（对全部样本求和，不取平均）：

$$\delta_o=(\hat y-y)\odot\hat y\odot(1-\hat y),\qquad
\delta_h=(\delta_oW_2^\top)\odot H\odot(1-H),$$

$$\nabla W_2=H^\top\delta_o,\quad \nabla b_2=\textstyle\sum\delta_o,\quad
\nabla W_1=X^\top\delta_h,\quad \nabla b_1=\sum\delta_h.$$

全批量动量更新，$\varepsilon$ 为学习率，$\alpha$ 为动量系数：

$$v\leftarrow\alpha v-\varepsilon\nabla E,\qquad w\leftarrow w+v.$$

## 三、运行环境

- Python：3.10 或更高版本。
- numpy：1.23 或更高版本，用于数据构造与矩阵运算。

无需深度学习框架。

## 四、代码说明

### 1. 文件职责

| 文件 | 主要职责 |
| --- | --- |
| `main.py` | 统一入口：构造数据、初始化、训练、打印结果。 |
| `config.py` | 集中配置：`EXPERIMENT`（种子、位数、epoch 数、日志间隔）、`MODEL`（隐藏单元数、初始化范围）、`OPTIMIZER`（学习率、动量）、`TEST_INPUTS`（额外查看的输入）。 |
| `data.py` | `build_full_dataset` 生成全部 $2^6$ 种输入与标签；`mirror_labels` 计算镜像标签；`prepare_test_inputs` 校验额外输入。 |
| `model.py` | `sigmoid`（数值稳定）、`init_parameters`、`forward`、`loss_and_gradients`（半平方误差及手写反向传播梯度）、动量更新类 `MomentumSGD`，以及全批量训练函数 `train`（定期打印损失）。 |

训练后的准确率统计和预测打印直接写在 `main.py` 中，不单独拆分模块。

### 2. 默认配置与数据路径

- 种子 `1`，初始化范围 $[-0.3,0.3]$（权重与偏置），2 个隐藏单元，训练 `1425` 个 epoch，学习率 `0.1`，动量 `0.9`，每 `285` 个 epoch 打印一次损失。
- 数据由代码直接生成，无需下载或读取文件，不涉及路径。
- 可在 `config.py` 中修改种子、epoch 数、学习率、动量、初始化范围，以及 `TEST_INPUTS`（每行须为 6 个 0/1）。
- 默认配置已是论文的 64 样本全批量设置，无需扩大规模。差异与待确认项：论文初始化的具体细节（是否包含偏置、具体种子）无法确认；种子 `1` 与偏置随机初始化是本实现的选择。

### 3. main 执行流程

运行方式：`python main.py`。

1. 生成 64 个输入与标签，校验额外测试输入。
2. 按种子初始化参数，创建动量优化器。
3. 全批量训练 1425 个 epoch，每个 epoch 先求梯度再更新一次，打印第 1 个及每隔 285 个 epoch 的损失。
4. 打印训练集准确率与正确样本数，再逐行打印额外输入的“输入 -> 正确标签 -> 对称概率 -> 预测标签”。

检查目标现象：训练集准确率应为 100%（64/64），对称输入的概率接近 1，非对称输入接近 0。若换种子或 epoch 数导致准确率不足，属于该任务对初始化敏感的表现。
